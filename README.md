# 交变电流的产生 · 3D 交互课件

张专注物理制作的交流发电机教学课件，基于理想匀强磁场、匀速转动及纯电阻闭合电路。

**直接打开课件：https://zhangjinapr.github.io/alternating-current-3d-lesson/**

学生无需注册或登录。所有脚本与二维码均已内嵌，下载 `index.html` 后可用 Chrome 或 Edge 离线打开。

## 课堂演示

- 三维磁极、ABCD 线圈、连续双滑环、固定电刷及闭合电阻外电路。
- 同步实时正视图、俯视图，以及无可见边界的地面网格。
- 播放/暂停、连续循环、调速、反转、15° 步进、转角滑块、四个关键位置。
- 中性面可选显示，默认关闭：竖直灰色矩形平面，50% 透明，垂直于磁场且不随线圈转动。
- 速度 v 可选显示；红色感应电流箭头及 i 标注可选显示。正弦图像固定在右侧演示选项上方，始终显示，纵坐标为 i，最大值标为 i_max 和 −i_max。
- 手机支持单指旋转、双指捏合缩放；竖屏完整显示模型，控制按钮适配触摸。
- 左键旋转视角，右键平移发电机整体，正弦图像位置固定；复位恢复发电机位置。滚轮缩放、视角切换、专注演示、全屏。自动旋转观察视角默认关闭。
- 平整的同色浅色滑环标记随环转动，显示开关默认开启；完整滑环不分段。
- “张专注物理”水印，页面底部微信联系与自愿打赏二维码。

空格：播放/暂停；左右方向键：步进；F：全屏。操作转角滑块、步进或关键位置按钮时暂停，便于讲解。

## 物理约定

磁场从 N 指向 S。θ 为线圈法线与磁场的夹角。正向转动时 i = Iₘ sin θ；反向转动时电流符号反转。电流正方向为 B → A → 外电路 → D → C → B。

曲线按当前转速的最大电流归一化；速度箭头用于展示方向。正视图的点叉表示向观察者/远离观察者的矢量。地面网格和滑环色差是观察辅助。

## 修改与检查

修改 `build.py` 中的 HTML/CSS/JavaScript，然后运行：

```sh
python build.py
node verify.cjs
node verify_loop.cjs
node verify_right_drag.cjs
python -m http.server 8000
```

生成的 `index.html` 与源码一并提交，GitHub Pages 从 `main` 分支根目录发布。
